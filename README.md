## Задача

Даны два списка целых чисел `nums1` и `nums2`. Нужно вернуть числа, которые встречаются в обоих списках. Каждое число должно появиться в результате один раз. Порядок элементов может быть любым.

## Решение

В файле `intersection.py` задача решена методом `intersection` класса `Solution`. Сначала я преобразую `nums2` в множество `second`, чтобы быстро проверять, встречается ли число во втором списке.

Затем я прохожу по `nums1` и добавляю в множество результата только числа, для которых выполняется `i in second`. Множество хранит каждое значение один раз. В конце я преобразую его в список и возвращаю.

## Почему это работает

Каждый элемент результата взят из `nums1` и прошёл проверку на наличие в `second`, поэтому он встречается в обоих списках. Если число есть в обоих списках, при обходе `nums1` оно пройдёт эту проверку и попадёт в результат. Повторные добавления того же числа состав множества не меняют.

## Сложность

Пусть `n` — длина `nums1`, а `m` — длина `nums2`.

- Время — **O(n + m)** в среднем. Создание `second` занимает O(m) в среднем. Затем я один раз прохожу по `nums1`, а проверка принадлежности множеству в среднем занимает O(1).
- Дополнительная память — **O(m)**. В `second` хранится не больше `m` чисел, а число общих элементов не превышает размер `second`.

## Примеры

| `nums1` | `nums2` | Один из допустимых результатов |
|---|---|---|
| `[1, 2, 2, 1]` | `[2, 2]` | `[2]` |
| `[4, 9, 5]` | `[9, 4, 9, 8, 4]` | `[4, 9]` |
| `[1, 2]` | `[3, 4]` | `[]` |

## Запуск

Из папки проекта выполните:

```bash
python3 -c 'from intersection import Solution; print(Solution().intersection([1, 2, 2, 1], [2, 2]))'
```

Команда выводит `[2]`.
